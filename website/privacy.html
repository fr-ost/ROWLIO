Privacy

{{name}} is built so that your data never has to leave your computer.

Summary

  • {{name}} does not collect, transmit, sell or share any data.
  • There is no account, no server, no analytics, no telemetry, no advertising and no remote AI service.
  • {{name}} reads a page only after you invoke it on that page.
  • Extracted data is kept in memory in the workspace tab. It is written to disk only when you save a project or export a file.
  • You can delete everything {{name}} stores, at any time.

What {{name}} reads

When you click the {{name}} icon (or use one of its keyboard shortcuts) on a tab, Chrome grants the extension temporary access to that tab. {{name}} then reads the content of that page, the same content you can see, to show what the page contains and to perform the extraction you ask for.

{{name}} does not read pages you have not invoked it on, does not run in the background and does not record your browsing history. Password fields are not read.

Removing the extension removes its storage. Nothing is synchronised between devices.

What {{name}} sends

Nothing. The extension contains no code that performs network requests, and its pages run under a Content Security Policy that makes the browser block connections to any remote server.

The page you are extracting from keeps behaving as usual: when {{name}} follows a next-page link, scrolls a feed, or opens the addresses in a list you gave it, the website loads its own content exactly as if you had clicked, scrolled or typed the address yourself.

The extension shows two credit links (to {{company}} and to the developer). They are ordinary links and contact those sites only if you click them.

Permissions

  • activeTab: temporary access to the tab you invoke {{name}} on.
  • scripting: lets {{name}} run its own bundled script in that tab.
  • Optional access to a single site, only if you ask for it, confirmed by Chrome.

This website

This website is static. It sets no cookies, loads nothing from third parties and contains no analytics. Your sound preference is kept in your browser's local storage. Like any website, the company that hosts it can see ordinary request data, such as IP addresses, in its server logs.
