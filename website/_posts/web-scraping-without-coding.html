Web scraping means collecting information from web pages in a structured form, usually rows and columns. For years that meant writing a script. Today a browser extension can do the common cases with a few clicks. This guide explains how that works, so you know what to expect and what to do when a page does not cooperate.

What "structured data" means

A product page shows a name, a price, a rating and a photo. To a person that is obvious. To a computer the page is a long tree of nested elements with no labels saying "this is the price". Scraping is the step that turns that tree into a table where each row is one product and each column is one kind of fact.

Once data is in rows, you can sort it, filter it, count it, chart it or load it into another program. That is the whole point.

How no-code tools find the data

Web pages are repetitive. A list of twenty search results is the same block of HTML twenty times with different text inside. No-code scrapers exploit this in three ways.

  • Tables. An HTML table already has rows and columns. The tool reads them directly.
  • Repeating items. You click one item, such as one product card. The tool looks for sibling elements with the same structure and treats each as a record.
  • Fields inside an item. Within each record, the tool looks for parts that appear in the same place every time: a heading, a link, an image, something that looks like a price or a date.

None of this needs artificial intelligence or a server. It is pattern matching on the page your browser has already loaded.

Your first extraction, step by step

Pick a page with a list of similar things: a shop category, a directory, a list of articles. Then, with Rowlio installed:

  1. Open the page and click the Rowlio icon.
  2. Choose Select items on the page.
  3. Click one item in the list. The similar items are outlined, and a panel shows how many were found and which fields were detected.
  4. If too little is outlined, press Wider. If too much, press Narrower.
  5. Rename the fields so the columns make sense, remove the ones you do not need, and confirm.
  6. Review the rows in the data preview and export them.

The first attempt takes a few minutes. After that it takes seconds, and you can save the setup as a recipe so the same site works with one click next time.

When the automatic detection gets it wrong

It will, sometimes. Pages are built in countless ways. The usual fixes:

  • Only part of each item is selected. You clicked something inside the card, and the tool matched that inner element. Go wider.
  • A field is missing. Add it by clicking the value inside one record. The tool finds the same spot in the others.
  • Some rows have an empty cell. Often correct: that item really has no rating or no discount. Check one on the page before assuming an error.
  • Nothing repeats. Click a second example. Two examples are enough to work out what they have in common.

If a page still resists, a hand-written selector gives you full control. CSS selectors and XPath are easier than they look.

What no-code scraping cannot do

It helps to know the limits before you start.

  • It reads what the browser shows. Content behind a login you do not have, or behind a paywall, is not available, and a responsible tool will not try to get around that.
  • Text inside images is not text. A price baked into a banner image cannot be read without OCR.
  • Content in embedded frames from another site is walled off by the browser for security reasons.
  • Very large jobs, such as hundreds of thousands of pages, are a job for a programmed crawler with proper infrastructure, not a browser extension.

Good habits from day one

  • Check the site's terms and take only what you need. Is web scraping legal? covers the questions to ask.
  • Go slowly. When collecting several pages, leave a delay between them. You are a guest on someone else's server.
  • Keep the source. Record the page address and the date with your data. You will want it when someone asks where a number came from.
  • Look before you export. Scan the rows for obvious problems. Five seconds here saves an hour later.
