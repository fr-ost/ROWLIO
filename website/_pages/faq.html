Privacy and permissions

Where does my data go?

Nowhere. Extraction, cleaning and export all happen inside your browser. Data is stored on your device only when you save a project, and you can delete it at any time.

Which permissions does it ask for?

Two: "activeTab", which gives temporary access to the tab you click the icon on, and "scripting", which lets the extension run its own bundled script in that tab. It has no access to other tabs or to your browsing history.

Does it track me or show ads?

No. There are no analytics, no telemetry and no advertising in the extension.

Can it read pages I have not clicked it on?

No. Chrome grants access to a page only when you click the {{name}} icon or use one of its keyboard shortcuts there. You can choose to always allow a specific site, and remove that again in Settings.

What it can extract

What kinds of data can it extract?

Tables, repeating items such as product cards and search results, links, images, contact details shown on the page, lists, headings and page metadata including structured data.

Does it work on every website?

It works on pages you can open in your browser. Chrome blocks all extensions on its own pages and on the Chrome Web Store. Content inside frames from another site, PDFs and text inside images cannot be read.

Can it collect data from several pages?

Yes. It can follow next-page links and page numbers, scroll pages that load more as you go, and run the same extraction over a list of addresses you provide. Every run has limits you set and a Stop button.

Does it download images?

No. It lists image addresses and their details. It does not download the image files.

Does it handle non-English text?

Yes. Text in any language is preserved from the page through to the exported file.

Export

Which file formats can I export?

CSV and Excel are the most used. Other formats are available in the export dialog, and you can copy rows to the clipboard to paste into a spreadsheet.

Will the file open correctly in Excel?

Yes. The Excel export keeps text, numbers and dates as they should be. For CSV, a marker is added so that Excel reads non-English characters correctly.

Can I import a file I already have?

Yes. You can open a CSV, TSV or JSON file and clean it with the same tools. Excel files cannot be imported.

Limits and conduct

Can it get around logins, paywalls or CAPTCHAs?

No, and it will not. {{name}} reads what your browser already shows you.

Is it a crawler?

No. It does not run in the background or discover pages on its own. Multi-page runs are started by you, bounded by limits you set and can be stopped at any moment.

Is web scraping legal?

It depends on what you collect, how, and where you are. You are responsible for respecting each website's terms and the law. Our guide Is web scraping legal? explains the questions to ask. It is not legal advice.

How much data can it handle?

Tables with tens of thousands of rows work well. Very large jobs, such as hundreds of thousands of pages, need a different kind of tool.
